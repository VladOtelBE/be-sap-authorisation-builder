## Structure
- **1 space per Business Profile** (end users see one entry in the space menu per role).
  Exception: a profile spanning several clearly distinct domains (> ~40 tiles) → 1 space per domain; ask user.
- **Pages = business process areas.** Default grouping key: matrix `BPML L2`
  (e.g. `1.2 Business Partner`, `1.3 Material Master`, `1.4 BOM`, `1.5 Prices`).
  Merge areas with < 3 tiles into a neighbour page only if functionally related; otherwise keep.
- **Sections inside a page = lifecycle** in this order: `Create & Maintain` → `Display & Analyse` → `Tools`.
  - create/change/maintain/manage actions → Create & Maintain
  - display/explode/compare/list/report → Display & Analyse
  - export/import/mass tools → Tools
- Page order follows the BPML numbering; tile order inside a section follows the matrix row order.

## Naming
| Object | Technical (config `naming`) | End-user name |
|---|---|---|
| Space | `Z_VOT_BEMIND_SP_<KEY>` | Business profile name in business language, e.g. "Master Data Management" |
| Page | `Z_VOT_BEMIND_PG_<KEY>_<AREA>` (AREA ≤ 6 chars: BP, ART, BOM, PRICE…) | Process area, e.g. "Business Partners" |
| Section | n/a (text) | "Create & Maintain", "Display & Analyse", "Tools" |
| Tile | target mapping (SO-action) | Standard tile title from system; suffix "(SAP GUI)" not needed – the WebGUI tile type is shown in the Excel only |

`<KEY>` = short profile key, uppercase, ≤ 10 chars (e.g. MDM_HQ). Propose and confirm with the user.
Check max lengths in `config/project.json`.

## Excel deliverable (D1) – sheets
1. **Overview** – profile, source matrix row, derivation, roles to build (`_ALL` + derived), counts.
2. **Spaces & Pages** – space tech/end-user name, page tech/end-user name, section, order.
3. **Tiles** – page, section, tile title, matrix ID, tile type (Fiori / WebGUI), semantic object-action,
   technical catalog, business catalog, access type (+ ACTVT), matrix comment, source.
4. **Roles** – role names, perimeter, org-level values.
5. **Gaps & Open Points** – unresolved entries, choices to confirm, questions.
Generated by `node scripts/build-layout-xlsx.mjs output/<KEY>/<KEY>_design.json`.
